# Contributing

Narrowly scoped schema, conformance, interoperability, and security
improvements are welcome. Open an issue before changing an admission field or
root boundary so the invariant and compatibility impact can be agreed first.

Every contribution must remain provider-neutral, fail closed on missing
authority, include adversarial tests, and avoid production keys, credentials,
customer policies, complete provider profiles, and private API contracts.

Run `python -m pytest -q` before opening a pull request. Report sensitive
findings through GitHub's private security-advisory interface.
