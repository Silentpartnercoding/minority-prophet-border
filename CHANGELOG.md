# Changelog

## 0.2.0 — 2026-08-10

- Add a container-ready OpenID AIIM sandbox joining verified OAuth access,
  exact-action Border admission, a signed admission stamp, deterministic Gate
  enforcement, and a durable harmless echo runtime.
- Add MCP initialization and tool discovery, operator-gated outbound OPRM and
  PKCE test routes, `private_key_jwt`, key generation, and readiness surfaces.
- Add adversarial tests for invalid authority, route and cargo substitution,
  duplicate JSON keys, oversized requests, callback replay, and concurrent
  exactly-once retries.

## 0.1.0 — 2026-08-07

- Publish the provider-neutral admission receipt, authority adapters,
  declaration binding, human-intervention record, and conformance vectors.
- Define verifier independence as a required property without claiming that
  Border discovers shared organizational control.
- State the bounded-issuance requirement for resistance to compromised keys.
