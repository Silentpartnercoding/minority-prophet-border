authenticated A2A caller and task remain bound to one exact MCP server, tool and
argument set before effect.

1. dispute the case definitions or decision rules;

useful as reproduction and will be reported unchanged. The valid case must
succeed, replay must cross separate instances with durable shared state, and an
effect counter outside the verifier determines whether a rejected action ran.
